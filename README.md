
# 🎓 Student Performance Predictor

A beginner-friendly Machine Learning project that predicts whether a student will pass or fail based on study hours and previous exam marks.

## 🚀 Technologies Used

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Google Colab

## 📊 Dataset Features

| Feature | Description |
|---|---|
| Study_Hours | Number of study hours |
| Past_Marks | Previous exam marks |
| Pass | 0 = Fail, 1 = Pass |

## 🧠 Machine Learning Algorithm

Logistic Regression (Classification)

## ⚙️ Project Workflow

1. Create Dataset
2. Data Preparation
3. Feature and Label Separation
4. Train-Test Split
5. Model Training
6. Model Prediction
7. Model Evaluation
8. New Student Prediction

## 📈 Evaluation

The model is evaluated using Accuracy Score and Classification Report.

Note: The dataset contains only 10 records and is intended for learning purposes.

## ▶️ How to Run

1. Download the notebook.
2. Open Google Colab.
3. Upload the `.ipynb` file.
4. Run all cells.
